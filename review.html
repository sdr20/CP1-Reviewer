1.1

What is Programming?

Learn
Programming is the process of writing instructions that tell a computer what to do.
A program is a set of instructions, written in a programming language, that a computer follows to do a task.

Why do we program? Computers are very fast and never get tired, but they cannot think for themselves. Programming lets us use that speed to solve problems, do repetitive work automatically, and process information accurately. A calculator app, a school grading system, and a mobile game are all programs.

How do humans give instructions to computers? A computer does not understand everyday English. Deep inside, it only understands machine language, which is made of 0s and 1s. So we write instructions in a programming language like C++, which is easier for people to read. A special tool called a compiler then translates the C++ code into machine language the computer can run.

How they connect: we start with a problem, write instructions to solve it, put those instructions together as a program, and the computer runs the program to produce output.

Example: The recipe analogy

Think of cooking adobo using a recipe.

A cook follows the recipe step by step, in order. A computer does the same with a program. If a step in the recipe is wrong, the dish comes out wrong. If an instruction in a program is wrong, the output is wrong. The computer does exactly what it is told, not what we meant.

A small real problem: "Find the total of two quiz scores."

1.2

Algorithm, Pseudocode, and Flowchart

Learn

Before writing any code, programmers first plan the solution. An algorithm is the plan itself. Pseudocode and a flowchart are two ways of writing that plan down: one uses words, the other uses pictures.

Problem
→
Algorithmthe step-by-step plan
→
Pseudocode / Flowchartthe plan in words or pictures
→
Programthe plan in C++
Algorithm
A finite, step-by-step set of clear instructions for solving a problem.
Pseudocode
A plain-language description of an algorithm's steps. It looks a little like code but does not follow the strict rules of any programming language, and a computer cannot run it.
Flowchart
A diagram of an algorithm. It uses standard symbols for each kind of step, connected by arrows that show the order.

A. How to create an algorithm

A good algorithm has input (the data it starts with), output (the result), steps that are clear and in the right order, and it must finish after a limited number of steps.

  1. Understand the problem. Read it carefully and know exactly what you are asked to solve.
  2. Identify the input. What data do you need to start with?
  3. Identify the output. What result should you get at the end?
  4. Figure out the process. What calculations or decisions turn the input into the output?
  5. Write the steps in order. Number them, one action per step, beginning with Start and ending with End.
  6. Test it. Follow your steps using sample values and check that the answer is correct.
Example

Problem: Find the sum and average of two quiz scores.

Input:   score1, score2
Output:  sum, average
Process: add the scores, then divide the sum by 2

Algorithm:
Step 1: Start
Step 2: Get the first score (score1)
Step 3: Get the second score (score2)
Step 4: Add score1 and score2, store the answer in sum
Step 5: Divide sum by 2, store the answer in average
Step 6: Display sum and average
Step 7: End

Test with 18 and 20:  sum = 38, average = 19  ✓

B. How to write pseudocode

Pseudocode uses short keywords written in capital letters. There is no single official format, but these are the common ones:

KeywordMeaning
START / ENDBeginning and end of the algorithm
INPUT (or READ, GET)Receive data
SET / COMPUTEStore a value or do a calculation
IF ... THEN ... ELSE ... ENDIFMake a decision
DISPLAY (or PRINT, OUTPUT)Show the result
  1. Begin with START.
  2. Write the INPUT lines for the data you need.
  3. Write the processing steps, one action per line, using simple words and math.
  4. Write IF ... ELSE if the algorithm needs a decision, and indent the lines inside it.
  5. Write the DISPLAY line for the output.
  6. End with END.
  7. Check it by tracing it with sample values, the same way you tested the algorithm.
Example 1: Sum and average 
START
  INPUT score1, score2
  SET sum = score1 + score2
  SET average = sum / 2
  DISPLAY sum, average
END
Example 2: Passed or failed 
START
  INPUT score
  IF score >= 75 THEN
      DISPLAY "Passed"
  ELSE
      DISPLAY "Failed"
  ENDIF
END

Notice there are no semicolons, no #include, and no data types. Pseudocode is for people to read, so correct C++ syntax is not required.

C. How to draw a flowchart

Each symbol in a flowchart has a specific meaning:

TerminalOval. Marks the start and end.
Input / OutputParallelogram. Getting data or showing results.
ProcessRectangle. A calculation or action.
DecisionDiamond. A yes/no question with two paths.
FlowlineArrow. Shows the direction of the steps.
ConnectorSmall circle. Joins parts of a flowchart that are far apart.
  1. Write the algorithm first so you know every step.
  2. Draw a Start terminal (oval) at the top.
  3. Draw an input parallelogram for each piece of data you need.
  4. Draw a process rectangle for each calculation.
  5. Draw a decision diamond for each yes/no question, with two labeled paths coming out: Yes and No.
  6. Draw an output parallelogram to display the result.
  7. Draw an End terminal (oval) at the bottom.
  8. Connect every symbol with arrows, usually from top to bottom, so there is one clear path to follow.
  9. Trace it with sample values to make sure it gives the correct output.
Example 1: Sum and average
Example 2: Passed or failed
AlgorithmPseudocodeFlowchart

Written withNumbered steps in everyday languageKeywords like INPUT, SET, IF, DISPLAYSymbols connected by arrows

None of the three can run on a computer. They are planning tools. The plan only runs after it is turned into a real program, such as one written in C++.

1.3

What are Variables?

Learn
A variable is a named storage location in the computer's memory that holds a value.

Think of a variable as a labeled box. The label is the variable's name, and what is inside the box is its value. Programs need variables because they must remember information while they run, such as a student's age or a quiz score.

     age              ← the label (variable name)
  ┌────────┐
  │   20   │          ← what is inside (value)
  └────────┘

Here is how to create a variable in C++:

intdata type
agevariable name
=assignment
20value
;ends the statement
int  → data type (what kind of value: a whole number)
age  → variable name (the label we use to refer to it)
=    → assignment (store the value on the right into the variable)
20   → value (the data being stored)

Variable and value: the name stays the same, but the value inside can change.

int age = 20;   // age holds 20
age = 21;       // now age holds 21 (the old value 20 is replaced)

Note: the text after // is a comment. The computer ignores it. It is only there to explain the code to people.

1.4

Purpose of Variables

Learn

Programmers use variables so their programs can work with information. Each variable below stores one piece of data:

int age = 20;
int score = 95;
int numberOfStudents = 40;

Variables allow programs to:

Store data
Keep a value in memory, like score = 95.
Use data later
Use the stored value again anywhere in the program.
Change values
Replace a value, like updating a score.
Perform calculations
Add, subtract, multiply, or divide stored values.
Work with user input
Store information the user types, like their age.
Make code readable
A name like score explains what the number means.
Example: Changing a variable changes the result 
int price = 50;
int quantity = 3;
int total = price * quantity;   // total is 150

If we change only one line, int quantity = 4;, then total becomes 200. The calculation stays the same, but the result changes because the value inside the variable changed.

1.5

High-Level vs Low-Level Programming Languages

Learn

High-Level Languages

Designed to be easier for humans to read and write. They use words and symbols that look a bit like English and math, and they hide the hardware details from the programmer.

Examples: C++, Python, Java, JavaScript

High-level code must be translated into machine language before the computer can run it.

Low-Level Languages

Closer to the computer's hardware. They are harder for people to read, but they give very direct control of the processor.

Machine language is made of binary (0s and 1s). It is the only language the processor understands directly.

Assembly language uses short words called mnemonics, like MOV and ADD, in place of binary. A tool called an assembler converts it to machine code. Each processor type has its own assembly language.

From people to hardware:

You (the programmer)
→
High-level languageC++, Python, Java, JavaScript
→
Assembly languageMOV, ADD
→
Machine language0s and 1s
→
Computer hardware
Example: The same kind of instruction at different levels
High-level (C++)
int letter = 97;
Assembly (x86)
MOV AL, 61h
Machine code (x86)
10110000 01100001

All three put the number 97 (written as 61 in hexadecimal) into storage. The assembly and machine code lines are the same instruction for an x86 processor: "move 97 into register AL". Notice how much easier the C++ line is to read.

FeatureHigh-LevelLow-Level
Human readabilityEasierMore difficult
Hardware abstractionHigher (hides hardware details)Lower (close to the hardware)
ExamplesC++, Python, JavaAssembly, Machine Code
Ease of programmingGenerally easierGenerally harder
1.6

Who Created C++?

Learn

C++ was created by Bjarne Stroustrup, a Danish computer scientist working at Bell Labs. He began the work in 1979, and the language kept developing through the early 1980s.

It started as an extension of the C programming language. Stroustrup added new features on top of C, so at first it was called "C with Classes". In 1983, the name was changed to C++.

The name comes from ++, the increment operator (you will learn it in Lesson 4). It means "add one", so C++ suggests "one step beyond C".

1979Work begins on "C with Classes" at Bell Labs
→
1983The name C++ is adopted
Creator:        Bjarne Stroustrup
Started:        1979
Original name:  C with Classes
C++ name:       1983
Location:       Bell Labs
Exam tip: 1979 is when development started (as "C with Classes"). 1983 is when it was named C++. Do not mix these up.

REMEMBER

  • Programming is writing instructions for a computer. A program is a set of those instructions.
  • An algorithm is a step-by-step plan. Pseudocode writes the plan in plain, code-like words. A flowchart draws it with symbols: oval (start/end), parallelogram (input/output), rectangle (process), diamond (decision).
  • A variable is a named storage location that holds a value. The value can change.
  • In int age = 20;, int is the data type, age is the name, = is assignment, and 20 is the value.
  • High-level languages (C++, Python, Java, JavaScript) are easier for humans. Low-level languages (assembly, machine code) are closer to the hardware.
  • C++: Bjarne Stroustrup, Bell Labs, started 1979 as "C with Classes", named C++ in 1983.

COMMON MISTAKES

✗ Wrong
int 2age = 20;
✓ Correct
int age2 = 20;

Invalid variable name. A variable name cannot start with a number.

✗ Wrong symbol

Using a rectangle for a yes/no question like "score >= 75?"

✓ Correct

Decisions use a diamond with two paths, Yes and No. Rectangles are for processes.

✗ Missing parts

A flowchart or pseudocode with no Start or End.

✓ Correct

Always begin with Start and finish with End so it is clear where the algorithm begins and stops.

✗ Wrong idea

"C++ was named in 1979."

✓ Correct

Work began in 1979 as "C with Classes". The name C++ came in 1983.

✗ Wrong idea

"Assembly is a high-level language because it uses words."

✓ Correct

Assembly is low-level. Its words (mnemonics) map almost directly to machine instructions.

✗ Wrong idea

"The computer will figure out what I meant."

✓ Correct

A computer follows instructions exactly. Wrong instructions give wrong output.

2.1

#include <iostream>

Learn

#include is a preprocessor directive. It tells the compiler to bring in (include) the contents of another file before compiling your program. Think of it as saying "add this toolbox to my program".

<iostream> is the toolbox we bring in. Its name means input/output stream. It is part of the C++ standard library and provides standard input and output features. The most important one for now is cout, which displays output on the screen.

#include <iostream>
→
Provides input/output functionality
→
Allows us to use cout

Without this line, the compiler does not know what cout is, and the program will not compile.

2.2

using namespace std;

Learn

std is short for standard. All the names in the C++ standard library, like cout, belong to a group called std.

A namespace is a named group that holds names. It prevents confusion when two things have the same name. Think of two students named Ana in different sections. Saying "Ana from Section A" makes it clear which Ana you mean.

The full name of cout is std::cout, which means "the cout that belongs to std". The :: connects the group to the name.

Without using namespace std;
std::cout << "Hello";
With using namespace std;
using namespace std;

cout << "Hello";

Both print Hello. They are two ways of reaching the same cout. The line using namespace std; simply lets you skip writing std:: every time.

2.3

int main()

Learn

main() is the main function. It is the starting point of every standard C++ program. When you run the program, the computer looks for main() and begins executing the statements inside its curly braces, from top to bottom.

A program needs exactly one clear place to start, the same way a book starts at page 1. In C++, that place is always main().

The word int in front means main() gives back an integer (a whole number) when it finishes. That number is sent to the operating system, which is why we end with return 0;.

Program starts
→
main()
→
Statements executetop to bottom, inside { }
→
Program ends
2.4

cout

Learn

cout (say "see-out", short for character output) is used to display output on the screen.

The << symbol is the insertion operator. It sends whatever is on its right side to cout, which shows it on the screen. You can picture the arrows pointing toward cout: the data flows into the output.

  • Text inside double quotes is printed exactly as written, without the quotes.
  • Numbers can be printed without quotes.
  • You can chain several << in one statement to print several things in a row.
Examples 
cout << "Hello";
Hello
cout << 25;
25
cout << "Age: " << 20;
Age: 20

The space after the colon is inside the quotes, so it is printed too.

int age = 20;
cout << "Age: " << age;
Age: 20

A variable prints its value, not its name.

cout << 5 + 3;
8

No quotes, so C++ calculates first.

cout << "5 + 3";
5 + 3

In quotes, so it is just text.

Watch out: cout does not move to a new line by itself. cout << "Hi"; cout << "There"; prints HiThere on one line.
2.5

return 0;

Learn

return 0; ends main() and tells the operating system that the program finished successfully. By convention, 0 means success.

It is usually the last statement inside main(), just before the closing brace }.

REMEMBER

  • #include <iostream> brings in input/output features so you can use cout.
  • std means standard. using namespace std; lets you write cout instead of std::cout.
  • Execution begins in main(). int means it gives back a whole number.
  • cout << displays output. Text goes in double quotes. << is the insertion operator.
  • return 0; means the program ended successfully.
  • Statements end with ;. The body of main() goes inside { }.

COMMON MISTAKES

✗ Missing semicolon
cout << "Hello"
✓ Correct
cout << "Hello";

Every statement must end with a semicolon.

✗ Wrong arrow direction
cout >> "Hello";
✓ Correct
cout << "Hello";

cout uses <<. The arrows point toward cout.

✗ Capital letters
Cout << "Hello";
✓ Correct
cout << "Hello";

C++ is case-sensitive. Cout and cout are different names. The same goes for Main and main.

✗ Missing quotes around text
cout << Hello;
✓ Correct
cout << "Hello";

Without quotes, C++ thinks Hello is a variable name. Text must be inside double quotes.

✗ No using namespace std; and no std::
#include <iostream>

int main() {
    cout << "Hi";
    return 0;
}
✓ Correct
#include <iostream>

int main() {
    std::cout << "Hi";
    return 0;
}

Without using namespace std;, you must write the full name std::cout.

3.1

What are Data Types?

Learn
A data type tells the computer what kind of data a variable will store.
Data Type
→
Determines what kind of valuea variable can store

Think of containers in a kitchen. You put rice in a rice container and water in a bottle. In the same way, whole numbers go in an int variable and text goes in a string variable.

Declaring a variable means creating it by writing its data type and name:

dataType variableName = value;

3.2

Basic C++ Data Types

int (integer)

Used for whole numbers: positive, negative, or zero, with no decimal point.

int age = 20;
int score = 95;
int temperatureChange = -5;
Careful: if you store a decimal in an int, the decimal part is dropped (not rounded). int x = 7.9; stores 7.

char (character)

Used for a single character: one letter, digit, or symbol. A char value is written in single quotes.

char grade = 'A';
'A'
char
single quotes, exactly one character
vs
"A"
string
double quotes, text (even if it is only one letter)

'A' is a character. "A" is a string of text that happens to contain one letter. They are different types in C++, so char grade = "A"; is an error.

string

Used for text, which is a sequence of characters. A string value is written in double quotes.

#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Steven";
    cout << "Hello, " << name;
    return 0;
}
Hello, Steven

string comes from the standard library, so it is commonly used with #include <string>. Like cout, it belongs to std, so using namespace std; lets you write string instead of std::string. Some compilers let a program use string with only <iostream>, but including <string> is the correct and safe habit.

float

Used for decimal numbers with single precision.

float temperature = 36.5;

For now, just recognize float as a type for decimal values. It is usually accurate to about 7 digits.

double

Used for decimal numbers with greater precision than float.

double price = 99.99;

It is usually accurate to about 15 digits, roughly twice as precise as float.

float  → decimal, generally less precision
double → decimal, generally more precision

bool (Boolean)

Used for Boolean values. A bool can only be true or false. It represents a yes/no, true/false condition.

bool isStudent = true;
bool isGraduate = false;
Good to know: true and false are written without quotes. If you print a bool with cout, C++ shows 1 for true and 0 for false.

3.4

Rules for Declaring Variables

Learn
  1. A variable name can contain letters, numbers, and underscores (_).
  2. A variable name cannot start with a number.
  3. Variable names cannot contain spaces.
  4. Variable names cannot use reserved C++ keywords such as int, double, bool, return, true, and false.
  5. C++ variable names are case-sensitive. age, Age, and AGE are three different variables.
  6. Use meaningful variable names. numberOfStudents is much clearer than n.

Names made of more than one word are often written in camelCase (studentAge) or snake_case (student_age). Both are valid.

Examples
✓ Valid
int age;
int studentAge;
int student_age;
int age2;
✗ Invalid
int 2age;
Starts with a number.
int student age;
Contains a space.

REMEMBER

  • A data type determines what kind of data a variable can store.
  • int whole numbers, char one character, string text, float decimal, double decimal with more precision, bool true/false.
  • char uses single quotes 'A'. string uses double quotes "A".
  • Use #include <string> when you use string.
  • Names: letters, numbers, underscores only. No starting with a number, no spaces, no keywords. Case-sensitive.

4.5

Increment and Decrement Operators

Learn
++
Increment
Increases the value by 1.
int x = 5;
x++; // or ++x;
Result: x is 6
--
Decrement
Decreases the value by 1.
int x = 5;
x--; // or --x;
Result: x is 4

x++; is a short way to write x = x + 1; (or x += 1;). x--; is a short way to write x = x - 1;.

On a line by itself, x++; and ++x; do the same thing: both add 1. The difference only shows up when the value is used in the same statement, like int y = x++; or cout << x++;. That is the next topic.
4.6

Pre-Increment and Post-Increment VERY IMPORTANT

Learn

The position of ++ or -- decides when the change happens.

PRE: ++x / --x

The operator is before the variable. Change first, then use the new value.

POST: x++ / x--

The operator is after the variable. Use the current value first, then change it.

Post-increment 
int x = 5;
int y = x++;
Step 1: y gets 5          (use the current value of x)
Step 2: then x becomes 6  (change x after)

Final values:  x = 6
               y = 5
Pre-increment 
int x = 5;
int y = ++x;
Step 1: x becomes 6       (change x first)
Step 2: then y gets 6     (use the new value)

Final values:  x = 6
               y = 6
Post-decrement 
int x = 5;
int y = x--;
Step 1: y gets 5          (use the current value of x)
Step 2: then x becomes 4  (change x after)

Result:  x = 4
         y = 5
Pre-decrement 
int x = 5;
int y = --x;
Step 1: x becomes 4       (change x first)
Step 2: then y gets 4     (use the new value)

Result:  x = 4
         y = 4

The same rule works with cout:

int x = 5;
cout << x++;   // prints 5
// now x is 6
int x = 5;
cout << ++x;   // x becomes 6 first
// then it prints 6

    REMEMBER

    • / with two integers drops the decimal: 7 / 2 is 3. % gives the remainder: 10 % 3 is 1.
    • x += 5 means x = x + 5. The same pattern works for -=, *=, /=, %=.
    • = means assignment. == means comparison.
    • Comparison and logical operators give true or false.
    • && needs both true. || needs at least one true. ! flips the value.
    • Pre (++x, --x): change first, use second. Post (x++, x--): use first, change second.

    COMMON MISTAKES

    ✗ Wrong idea
    int result = 7 / 2;   // "result is 3.5"
    ✓ Correct
    int result = 7 / 2;   // result is 3

    Both numbers are integers, so the decimal part is dropped.

    ✗ Using = to compare
    x = 5    // this STORES 5 in x
    ✓ Correct
    x == 5   // this CHECKS if x is 5

    One equal sign assigns. Two equal signs compare.

    ✗ Wrong idea
    int x = 5;
int y = x++;   // "y is 6"
    ✓ Correct
    int x = 5;
int y = x++;   // y is 5, x is 6

    Post-increment uses the old value first, then adds 1.

    ✗ Wrong idea

    "% means percent."

    ✓ Correct

    In C++, % is the modulus operator. It gives the remainder.
